This is a Chinese source-study course, paired with learn-pi-agent and learn-claude-code.

- Read `source.lock.json` before making claims about upstream versions or behavior.
- The course source checkout is read-only. Make upstream contributions in the separate sibling `minimax-code-contrib` checkout.
- Read source through `lab/source.mjs`; keep source citations and experiments tied to the pinned commit.
- Distinguish source inspection, synthetic offline tests, and live CLI/provider evidence. Never fabricate recordings or contributor/PR status.
- Content lives in `course/`; the table of contents is `course/syllabus.json`. Quote source with `@mm file#symbol` (read from the pinned Git object); `.authoring` style rules: concrete scenarios, real excerpts with explanation, readable lab output, no defensive wording.
- Preserve the series reading design. Run `npm run check` and `npm run build` after content or builder changes; these execute the declared offline labs.
- Upstream currently accepts collaborator PRs only. Recheck CONTRIBUTING and actual repository policy before external contribution actions.
- Do not send issues/comments or application messages without explicit user authorization. Prepare reviewable English drafts first.
